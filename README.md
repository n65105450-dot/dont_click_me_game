# 🐟 Don't Catch Me!

A fun and interactive underwater game where the fish escapes when you try to catch it! 😈🐟

## 🎮 About the Game

You have 30 seconds to catch the magical fish and get the highest score possible.

But be careful... the fish detects your mouse and quickly escapes! 😂

At the end of the game, you'll receive a funny surprise gift based on your score. 🎁

## ✨ Features

- 🐟 Mouse proximity detection
- ⚡ Fast escaping fish
- ✨ Magic glow effect
- 💬 Interactive fish speech bubbles
- 😂 Random funny messages
- ⏱️ 30-second countdown timer
- 🪼 Animated underwater background
- 🌊 Glowing jellyfish and coral decorations
- 📱 Responsive design
- 🎁 Score-based funny reward system
- 🔄 Play Again functionality

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

## 🚀 How to Play

1. Click **START GAME**
2. Move your mouse near the fish
3. Try to catch the escaping fish
4. Score as high as possible in 30 seconds
5. Get your funny reward! 😂🎁
